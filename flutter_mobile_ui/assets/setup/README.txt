Setup flow product photos. Drop them here; the setup screens pick them up
automatically. Until a file exists, the app shows a labeled placeholder in
the same spot and shape.

monitor.png: the whole monitor, screen lit.
  Welcome page, full width and bleeding off the bottom of the screen. The
  frame is tall and narrow: about 2:3 on a 412dp-wide phone and about 3:4
  on a 360dp one, cropped to fill (cover) with the top corners rounded.
  The sides get cropped, so shoot it portrait and keep the monitor narrow
  and centered with margin above and below.
  Recommended: at least 1080 x 1620 px (2:3 portrait).

monitor-screen.png: a close-up of the monitor's LCD.
  Pairing and Device ID steps, in a wide band 168dp tall (about 2.2:1 on
  a 412dp phone, 1.9:1 on a 360dp one), cropped to fill. Frame the LCD
  centered and horizontal, so the crop keeps the code readable.
  Recommended: at least 1080 x 480 px.
